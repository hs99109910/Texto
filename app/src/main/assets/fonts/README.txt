Persian fonts
=============

Drop the font files into this folder, then rebuild the app. Settings -> Font
lists them and falls back to the system font for any file that is missing.

Expected file names (case-insensitive, .otf also accepted):

  BKoodak.ttf       -> B Koodak     (ب کودک)
  BNazanin.ttf      -> B Nazanin    (ب نازنین)
  BKamran.ttf       -> B Kamran     (ب کامران)
  IranNastaliq.ttf  -> Iran Nastaliq (ایران نستعلیق)

Alternative names that are also picked up:
  "B Koodak.ttf" / "b_koodak.ttf", "B Nazanin.ttf" / "b_nazanin.ttf",
  "B Kamran.ttf" / "b_kamran.ttf", "Iran Nastaliq.ttf" / "iran_nastaliq.ttf"

These are commercially licensed typefaces and are not shipped with the
repository -- supply your own licensed copies.
